# Barbearia 43 — Template V2

Site estático (HTML, CSS e JS sem frameworks). Abra `index.html` no navegador.

## Personalizar para outra barbearia
1. Edite **somente `config.js`**: `negocio`, `tema`, `contato`, `unidades`, `galeria`, `equipe` e `depoimentos`.
2. Para cada unidade configure `id` único, nome, endereço, mapsUrl, whatsapp, horários e `categorias` de serviços com preços numéricos.
3. Substitua a logo em `assets/imagens`, apontando a nova imagem no `config.js`.
4. Fotos da galeria são opcionais; use `src: ""` para mostrar um placeholder. Não há fotos do Instagram no site.
5. Publique os arquivos em GitHub Pages ou Netlify (site estático, sem etapa de build).
